# Abdul Hakim Portfolio

Portfolio site for Abdul Hakim bin Shaisham: integrity and governance work, and the AI tools built for it.

## Run locally

```sh
npm install
npm run dev
```

Vercel uses `npm run build` and serves the generated `dist` directory.

## Project structure

- `index.html` — content and page structure
- `src/styles.css` — layout, light and dark themes
- `src/main.js` — mobile navigation and small UI behaviour

Each project carries a status label: **Live** (in use, linked), **Prototype** or **Concept**. The Rangka OACP card shows an illustrative mock of the app's form flow, not a screenshot.
